1. JavaScript String Object

A String object is used to store and manipulate text. JavaScript provides several predefined methods to perform operations on strings.

Common String Methods

1. length

Returns the number of characters in a string.

"Hello".length

Output: 5

2. toUpperCase()

Converts all characters into uppercase letters.

"hello".toUpperCase()

Output: HELLO

3. toLowerCase()

Converts all characters into lowercase letters.

"HELLO".toLowerCase()

Output: hello

4. charAt()

Returns the character at a specified position.

"JavaScript".charAt(0)

Output: J

5. indexOf()

Returns the first position of a specified character or text.

"JavaScript".indexOf("Script")

Output: 4

6. slice()

Extracts a portion of a string.

"JavaScript".slice(0, 4)

Output: Java

7. replace()

Replaces the first matching text with another text.

"Hello World".replace("World", "JavaScript")

Output: Hello JavaScript

8. trim()

Removes whitespace from the beginning and end of a string.

" Hello ".trim()

Output: Hello
